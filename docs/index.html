Hardware

  • Sensor: MPS20N0040D pressure bridge (50–100 mV FS)
  • AFE: AD620 instr. amp, gain ≈ 105  |  TLC2272 level shift @ 1.5 V
  • MCU: STM32F411CE (Black Pill), ADC → UART → PC
  • Bandwidth: ~1.2 kHz (TINA-TI verified)

Software Stack

  • Python multiprocessing — 3 worker processes + main
  • Bounded Queue(maxsize=20) — flow control / backpressure
  • scipy.signal.sosfilt — stateful IIR across chunks
  • find_peaks + oscillometric ratios → SYS/MAP/DIA

Oscillometric Method

  • Cuff inflated to ~180 mmHg, then slowly deflated
  • Oscillations appear between SYS and DIA pressure
  • Systolic: first peak ≥ 50% of max oscillation amplitude
  • MAP: peak with maximum oscillation amplitude
  • Diastolic: first peak ≤ 70% of max after MAP
